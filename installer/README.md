# shoulderkop-install.sh

Установщик shoulderkop «под ключ»: сам проверяет роутер, сам ставит недостающее —
podkop, sing-box-extended, shoulderkop — и сам применяет подписку.

Вопросов всего два:

1. ставить ли **sing-box-extended** (нужен для xhttp-узлов);
2. **ссылка на подписку** — можно нажать Enter и добавить её позже в LuCI.

Всё остальное (podkop, зависимости, режим, расписание) установщик решает сам.

## Требования

* **OpenWrt 24.10 или новее** — podkop 0.7.24+ не поддерживает 23.05;
* менеджер пакетов `apk` (OpenWrt 25.12+) или `opkg` (24.10);
* права root;
* ~15 МБ свободного места в `/overlay` для podkop и shoulderkop;
* доступ к `github.com` (при проблемах — `--mirror=`), `curl`/`wget`/`uclient-fetch` для
  скачивания.

Репозиторий с пакетами: **BranchSeeker/shoulderkop** (переопределяется `--repo=` или
переменной `SK_REPO`).

## Что делает

1. **Проверяет окружение.** Модель, версия OpenWrt, архитектура, память, место в
   `/overlay`, менеджер пакетов, доступ к GitHub, часы (через `ntpd` по IP — DNS может быть
   сломан именно из-за сбитого времени). Если чего-то критично не хватает — останавливается
   с понятным сообщением, а не ставит «наполовину».
2. **Ставит podkop.** Тихий шаг: если podkop нет или он старее `0.7.24`, берётся последний
   релиз с GitHub (`podkop` + `luci-app-podkop` + русский перевод, если он есть в релизе).
   * `https-dns-proxy` конфликтует с podkop, поэтому удаляется автоматически; его конфиг
     сохраняется в `/root/shoulderkop-backup/https-dns-proxy.config`.
   * `nextdns`, `getdomains`, `passwall`/`passwall2` — установщик не удаляет: он
     останавливается и просит убрать их вручную.
   * старый конфиг podkop копируется в `/etc/config/podkop.bak` (один раз).
   * на opkg сначала ставится `sing-box` из репозитория — иначе opkg откажется ставить
     podkop из-за неразрешённой зависимости.
3. **Ставит sing-box-extended** (если согласиться). Нужен `1.14.1-extended-2.7.2+`, даёт
   xhttp-узлы. Формат выбирается сам по свободному месту:
   * `apk` — если в релизе есть пакет под эту архитектуру и хватает места;
   * `compressed` — сжатое ядро в `/usr/libexec/sing-box-core.gz` + обёртка в
     `/usr/bin/sing-box` (ядро распаковывается в `/tmp` при первом запуске);
   * `plain` — обычный tar.gz, бинарник сразу в `/usr/bin/sing-box`.

   На время замены туннель гасится, после — поднимается. Если новая сборка не запустилась,
   установщик возвращает прежний бинарник. Если места или сборки под архитектуру нет —
   шаг пропускается с предупреждением, остальное ставится.
4. **Ставит shoulderkop + luci-app-shoulderkop** из релиза GitHub (`.apk` на 25.12+,
   `.ipk` на 24.10-), из локального каталога (`--local`) или HTTP-каталога (`--base-url`).
5. **Настраивает.** Автозапуск, режим `wifi` («Домашний интернет») по умолчанию, интервал
   urltest `30s`, автообновление подписки по расписанию. Если ссылка задана (или уже есть в
   конфиге) — сразу тянет подписку, заполняет секции podkop, перезапускает podkop и
   `rpcd`/`uhttpd`. Если подписка истекла — podkop и sing-box останавливаются, их автозапуск
   снимается, а cron продолжает проверять подписку (туннель вернётся сам после продления).
6. **Проверяет результат.** Версии sing-box и podkop, режим, интервал urltest, число секций
   podkop, запущен ли sing-box. В конце — короткая сводка и что делать дальше.

## Быстрый старт

```sh
# скачать и запустить — спросит только про extended и подписку
wget -O /tmp/sk-install.sh https://raw.githubusercontent.com/BranchSeeker/shoulderkop/main/installer/shoulderkop-install.sh
sh /tmp/sk-install.sh

# совсем без вопросов: extended + подписка + режим
sh /tmp/sk-install.sh --yes --url="https://panel.example.com/sub/TOKEN" --mode=lte

# только посмотреть, что будет сделано (ничего не меняет и ни о чём не спрашивает)
sh /tmp/sk-install.sh --dry-run
```

Если запускать через `wget -O - ... | sh`, ответы на вопросы прочитать не получится —
используйте скачивание в файл (как выше) либо флаги `--yes` и `--url=`.

## Повторный запуск

Скрипт можно запускать сколько угодно раз: он ничего не ломает и не ставит пакеты поверх
тех же версий.

* **shoulderkop**: сравнивает установленную версию с последним релизом GitHub. Совпадает —
  пишет `shoulderkop X уже установлен — это последняя версия` и идёт дальше (настройка,
  подписка). Есть новее — показывает `установлен X, в релизе Y` и спрашивает
  `Обновить shoulderkop X → Y?`.
* **podkop**: то же самое — установленная версия против последнего релиза, с таким же
  вопросом перед обновлением. `--force` переустанавливает без вопросов.
* **sing-box-extended**: если уже стоит подходящий extended — шаг пропускается;
  `--force` переустанавливает.
* **подписка**: если ссылка уже есть в конфиге, она просто обновляется заново.

Всегда берётся **последний** релиз (`releases/latest`); если GitHub недоступен,
установленные пакеты остаются как есть, а скрипт сообщает об этом и продолжает.

Если скрипт запущен без терминала (`wget -O - … | sh`) или с `--yes`, вопросы не задаются:
обновления ставятся сразу, как если бы на все вопросы ответили «да».
## Флаги

| Флаг | Описание |
| --- | --- |
| `--url=URL` | ссылка на подписку: обработать сразу, без вопроса |
| `-y`, `--yes` | без вопросов: extended ставится, подписка — только из `--url` |
| `--dry-run` | показать план и текущее состояние, ничего не менять |
| `--mode=lte\|wifi` | `lte` — «Обход БС» (всё в туннель), `wifi` — «Домашний интернет» (по умолчанию) |
| `--interval=1h` | период обновления подписки |
| `--urltest=30s` | интервал выбора сервера: `30s`, `1m`, `2m`, `3m`, `5m`, `10m` |
| `--schedule=0\|1` | обновлять подписку по расписанию (по умолчанию `1`) |
| `--force` | переустановить podkop и sing-box, даже если уже стоят |
| `--pkg=apk\|opkg` | принудительно выбрать менеджер пакетов (для отладки) |
| `--singbox-format=apk\|compressed\|plain` | принудительно выбрать формат sing-box |
| `--local=DIR` | ставить пакеты shoulderkop из локального каталога |
| `--base-url=URL` | HTTP-каталог со списком `.apk`/`.ipk` (нужен листинг) |
| `--repo=OWNER/REPO` | репозиторий GitHub с релизами shoulderkop |
| `--mirror=URL` | своё зеркало: скачивание идёт напрямую, а при ошибке — через него (по умолчанию пробуются `ghproxy.net`, `gh-proxy.com`, `ghfast.top`) |
| `--no-podkop` | не ставить podkop |
| `--no-singbox` | не ставить sing-box-extended (xhttp-узлы будут выкинуты) |
| `--no-shoulderkop` | не ставить shoulderkop |
| `-h`, `--help` | справка |

## Сколько места нужно

| Что | `/overlay` | `/tmp` |
| --- | --- | --- |
| podkop + shoulderkop | ~15 МБ | — |
| sing-box-extended, `compressed` | ~30 МБ | ~100 МБ на время установки |
| sing-box-extended, `plain` | ~90 МБ | ~170 МБ на время установки |

`compressed` — компромисс для роутеров с небольшим флешем: ядро лежит сжатым, при запуске
распаковывается в `/tmp` (нужно ~40 МБ ОЗУ под это). `plain` проще и быстрее, но требует
много места.

## Что меняется в системе

* ставится/обновляется `podkop`, `luci-app-podkop`, `sing-box-extended`, `shoulderkop`,
  `luci-app-shoulderkop`;
* может быть удалён конфликтующий `https-dns-proxy` (конфиг сохраняется);
* на opkg может сначала ставиться `sing-box` из репозитория, а затем его бинарник
  заменяется на extended из tar.gz (opkg об этом не знает — при `opkg upgrade sing-box`
  замена потеряется, повторный запуск установщика это исправит);
* включается автозапуск, по умолчанию — режим «Домашний интернет» и автообновление подписки
  (в `/etc/crontabs/root`);
* настройки podkop в режиме «авто» перезаписываются секциями shoulderkop: старые секции
  `main`/`proxy`/`exclusion` заменяются, приватные ключи в других секциях не затрагиваются;
* журнал установки: `/tmp/shoulderkop-install.log`.

## Коды возврата

| Код | Значение |
| --- | --- |
| 0 | успех (в том числе если часть шагов пропущена с предупреждением) |
| 1 | ошибка: нет места, не скачалось, не установилось |
| 2 | прервано (Ctrl+C) |

## Если что-то пошло не так

* **«нужен OpenWrt 24.10 или новее»** — на 23.05 podkop нужной версии не работает:
  обновите прошивку.
* **«podkop несовместим с …»** — удалите `nextdns`, `getdomains` или `passwall`
  (`opkg remove` / `apk del`), затем запустите установщик снова.
* **«нет доступа к github.com»** — проверьте интернет и DNS; можно подставить зеркало:
  `--mirror=https://ghproxy.net/` или указать `--local=/tmp/pkgs`.
* **«мало места в /overlay»** — освободите место; для sing-box-extended хватит
  `compressed`, но не ставьте его на 16 МБ флеш.
* **sing-box-extended не встал** — установщик сам вернёт прежний движок и напишет причину;
  можно повторить с `--singbox-format=compressed` или `--no-singbox`.
* **подписка не дала узлов** — проверьте ссылку: `shoulderkop update --url="..."`,
  журнал `/tmp/shoulderkop-install.log`, затем `shoulderkop status`.
* **подписка истекла** — установщик сам остановит podkop/sing-box и снимет автозапуск;
  после продления туннель поднимется при следующей проверке по расписанию (или сразу:
  `shoulderkop update`).
* **туннель не поднялся** — `logread -e podkop`, `podkop restart`.
